Research

Peer-reviewed publication and associated open-source resources for the WearMask system.

Paper

WearMask: Fast in-browser face mask detection with serverless edge computing for COVID-19

Authors: Zekun Wang, Pengwei Wang, Peter C. Louis, Lee E. Wheless, Yuankai Huo

Journal: Electronic Imaging, Volume 35, Issue 11, 2023

DOI: 10.2352/EI.2023.35.11.HPCI-229

Abstract summary

WearMask presents a lightweight face mask detection system that runs entirely in the web browser using YOLO-Fastest, NCNN, and WebAssembly. The design enables serverless edge computing: inference happens on the client device without uploading camera data to a remote server. This approach supports privacy-preserving, low-cost deployment for public-facing mask detection scenarios during the COVID-19 pandemic and beyond.

Reproducing experiments

  1. Clone mask-detector and install Python 3.8 dependencies.
  2. Train or use pretrained weights (best.pt / best.weights).
  3. Convert PyTorch → Darknet → NCNN → optimized NCNN following the repository README.
  4. Build the C++ WebAssembly module from facemask-detection.
  5. Deploy via GitHub Pages or run locally with python3 scripts/server.py.
