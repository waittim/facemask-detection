Privacy Model

How WearMask handles camera data and user privacy.

Client-side processing

WearMask performs all face mask detection entirely inside your web browser using WebAssembly. Camera frames are processed locally on your device. No images, video, or detection results are uploaded to a WearMask application server.

What is not collected

  • Camera images or video are not stored or uploaded.
  • Mask-wearing detection results are not sent to a backend.
  • No user accounts or personal identification is required.

Offline operation

After the WebAssembly model files are loaded, detection can continue even if you disconnect from the internet. The initial page load requires network access to download the application and model assets.
