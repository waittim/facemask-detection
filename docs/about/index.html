WearMask: In-browser Face Mask Detection

WearMask is an open-source, real-time face mask detection system that runs entirely inside a web browser. The project is also published as WearMask: Fast in-browser face mask detection with serverless edge computing for COVID-19.

What is WearMask?

WearMask (Web-based Efficient AI Recognition of Masks) detects whether people in a webcam feed appear to be wearing a face mask. Unlike cloud-based vision services, all inference happens on the user's device. No camera images or video are uploaded to an application server.

How is it different from cloud vision?

  • Privacy: Camera data never leaves the browser.
  • Serverless: No backend GPU or inference API is required.
  • Edge computing: Detection runs on the user's CPU via WebAssembly.
  • Open source: Deployment and training code are publicly available.

What does fully local inference mean?

After the page loads the WebAssembly model, detection runs on each video frame inside the browser. The application does not send images, video, or detection results to a WearMask server. You can disconnect from the internet after the model has loaded and detection will continue to work.
