Setup

How to get the best experience?

  • Launch the latest Chrome browser for best performance.
  • Open chrome://flags and enable all WebAssembly features.
  • Restart Chrome, open this page, and allow camera access.
  • Frame rate depends on your device CPU. Safari on iOS is supported but may run at a lower frame rate.

Project

Project overview

WearMask is a real-time, in-browser face mask detector built on YOLO-Fastest, trained with PyTorch, and run locally via NCNN and WebAssembly.

Both the deployment and training codebases are open source, with a peer-reviewed paper.
