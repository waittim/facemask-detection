Setup How to get the best experience?
  • Launch the latest Chrome browser for best performance.
  • Open chrome://flags and enable WebAssembly features if needed.
  • Restart Chrome, open this page, and allow camera access.
  • Safari on iOS is supported but may run at a lower frame rate.

Frame rate depends on your device CPU.

Privacy Privacy statement

Everything runs fully inside your browser via WebAssembly. No images or video leave your device.

Project Project overview

WearMask is a deep learning project based on Yolo-Fastest and NCNN. It's lightweight and runs entirely in your browser via WebAssembly.

This project is open-sourced on GitHub. Contributions are welcome.
