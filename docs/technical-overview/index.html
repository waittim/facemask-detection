Technical Overview

End-to-end architecture of the WearMask browser deployment and training pipeline.

Core AI Pipeline

WearMask combines YOLO-Fastest with Tencent NCNN framework compiled into WebAssembly for high-speed client-side C++ execution. 

Camera frame
  → browser <canvas>
  → C++ preprocessing (Emscripten)
  → WebAssembly runtime
  → NCNN inference
  → YOLO-Fastest decoding
  → bounding boxes and classes (Mask / No Mask)
  → canvas rendering

Hardware Acceleration

Leverages WebAssembly SIMD and multi-threading for fast real-time inference on modern CPUs.

Training and conversion pipeline

Model training and conversion are implemented in the mask-detector repository:

PyTorch training (YOLO-Fastest)
  → Darknet weights (.weights)
  → NCNN model (.param + .bin)
  → NCNN optimize (yolo-fastest-opt)
  → C++ inference wrapper (yolo.cpp)
  → Emscripten compile
  → WebAssembly (.wasm + .js + .data)
